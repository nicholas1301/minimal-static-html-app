# Teste Hackathon

Uma landing page estática em HTML (`index.html`) e um visualizador 3D do Sistema Solar (`solar.html`), sem dependências nem etapa de build. Abra os arquivos em um navegador para visualizar.

O deploy no GitHub Pages é feito automaticamente a cada push para `main`.
